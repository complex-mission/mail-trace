Mail Trace

End-to-end mail delivery diagnostics - probe every hop

Mail Trace is an open-source mail deliverability diagnostic: it opens a real SMTP session, records every hop from DNS through TLS, authentication and delivery, fully evaluates SPF, checks the sending IP's reverse DNS, and tells apart what each DNSBL return code actually means. Credentials are never persisted, logged or forwarded.
